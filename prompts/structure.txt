### Structure Checklist
For each item: PASS or FAIL. On FAIL give the exact fix.

1. H1 present and keyword-rich? FAIL → write exact H1: "[text]"
2. Opening hook: 2–3 sentences, no heading, specific stat/scenario, no banned opener? FAIL → write replacement hook.
   Banned: "Did you know", "In today's world", "In an era of", "In [year],"
3. Introduction: 2–3 paragraphs with problem + stakes + sourced evidence? FAIL → state what's missing.
4. 4–6 H2 body sections each with 3+ developed paragraphs? FAIL → list every failing section and its paragraph count.
5. H3s in at least 3 body sections? FAIL → name the sections and write the exact H3 to add.
6. FAQ with 5–6 H3 search-query questions? FAIL → write the missing questions exactly.
7. Conclusion with specific actionable CTA (not "contact us" / "learn more")? FAIL → write the exact CTA.
8. Word count above 2500? FAIL → estimate count and which sections to expand.

### Thin Sections
For each section under 3 paragraphs:
SECTION: "[heading]" | CURRENT: [N] paragraphs | ADD: [N] paragraphs covering [specific topics]
Mark sections with 0–1 paragraphs: CRITICAL — nearly empty.

### FAQ Audit
For each question: search-query phrased? (yes/no — if no, write replacement) | Contains specific fact? (yes/no — if no, specify what to add)

### Depth Gaps (up to 3)
