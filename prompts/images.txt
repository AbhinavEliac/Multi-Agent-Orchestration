Image recommendations (including any user-supplied custom images) are provided as structured data with:
- url: local image file path or web URL
- alt: descriptive alt text
- caption: short caption / description
- source_url: source attribution (web URL or "Custom Image")
- section: recommended section heading name
- context: the semantic topic and preceding text details that the image illustrates
- placement: explicit placement instruction
- is_custom: (boolean, if true, this is an important user-provided image that must be placed in its designated contextual section)

CRITICAL IMAGE RULES:
1. You MUST include EXACTLY the supplied images in the final article. Every supplied image is unique and must be placed.
2. Place each image IMMEDIATELY AFTER the paragraph or section whose preceding text and topic match the semantic context/details supplied for that image.
3. Every image MUST be rendered using the following markdown format:
   ![descriptive alt text](url)
   *Caption text (Source: [Source Domain](source_url))*
   (For custom images where source_url is not a web link, format as: *Caption text (Source: Custom Image)*)
4. Do not invent image URLs. Only use supplied `url` and `source_url` values.
5. Do not bundle all images together; distribute them contextually throughout the article after their respective matching paragraphs.
