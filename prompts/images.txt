Image recommendations (including any user-supplied custom images) are provided as structured data with:
- url: local image file path or web URL
- alt: descriptive alt text
- caption: short caption / description
- source_url: source attribution (web URL or "Custom Image")
- section: recommended section heading name
- context: the semantic topic and preceding text details that the image illustrates
- placement: explicit placement instruction
- is_custom: (boolean, if true, this is an important user-provided image)

=======================================================
CRITICAL IMAGE PLACEMENT RULES:
=======================================================
1. EXACT COUNT MATCH: If N images are provided in the Image Recommendations list, you MUST embed EXACTLY all N images across distinct body sections (one image per section). If 0 images are provided, do not insert any image tags.
2. ZERO REPETITIONS: Every image in the article must be 100% unique. Never reuse the same image URL, local path, or graphic twice under different captions.
3. CONTEXTUAL EMBEDDING: Place each image IMMEDIATELY AFTER the paragraph that discusses its specific topic, architecture, or data point (matching the image's `context` or `placement` hint).
4. MARKDOWN FORMAT: Render every image as:
   ![descriptive alt text](url)
   *Figure [N]: Short italic caption (Source: [Source Domain](source_url))*
   (For custom uploaded images where source_url is "Custom Image", format as: *Figure [N]: Caption text (Source: Custom Upload)*)
5. NEVER invent fake URLs. Use only the exact `url` values provided in the structured image list.
6. Distribute images evenly across sections rather than clumping them together.
